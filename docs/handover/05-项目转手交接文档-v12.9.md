## 三、技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | 原生 HTML/CSS/JS，**无框架、无构建** | 「双击 `index.html` 可离线运行」是硬约束 |
| 后端 | Cloudflare Pages Functions（`functions/api/*`） | 登录 / 账号管理 / 报价数据云端共享 |
| 存储 | 浏览器 `localStorage`（键前缀 `tagPricing_`）+ Cloudflare KV | KV 只存账号与云端默认配置 |
| 部署 | Cloudflare Pages + wrangler 3.112.0 | **必须 v3**，v4 不上传 Functions |
| 第三方 | SheetJS（`js/vendor/xlsx.full.min.js`，已本地化） | Excel 导入导出；离线可用 |

数据流：`data.js`（默认数据 + 迁移链）→ `localStorage` → `app.js`（计算/渲染）→ `saveToStorage`；
网页版另经 `auth.js` 与 KV 交互（账号）并轮询云端默认配置。

## 五、版本号规则与升版 SOP

### 规则
- **两段式 `vx.y` + 逢十进一**：`y ≥ 10` → `x+1` 且 `y-10`（不存在 v1.12，应为 v2.2）。
- `dataVersion`（迁移基线，当前 11.4）≠ 界面版本号，**升版脚本不得连带改它**。

### 升版写入点（完整清单，缺一个就是"陈旧标记"事故）

| 位置 | 说明 |
|---|---|
| `index.html` | `<title>`、`?v=` × 9、`setting-desc` |
| `login.html` | `?v=` × 3 |
| `js/app.js` / `js/data.js` / `js/auth.js` / `css/style.css` | 文件头注释版本号 |
| `CHANGELOG.md` | 顶部新增版本段落 |
| `README.md` / `TODO.md` | 顶部「当前版本」 |
| `docs/*.md` 头部 | 「当前版本」标记 |

⚠️ **两个坑（都踩过）**：
1. `docs/ISSUES.md` 是**全角冒号**格式 `当前版本：**vX.Y**`，与其它文档的 `当前版本 **vX.Y**` 不同——
   升版脚本要做**全格式匹配**，且 0 命中时必须报警而非静默跳过（v12.9 升版就漏过它）。
2. 历史注释里的旧版本号**要保留**（如 `// v12.8 修复：…`），只改"当前版本"标记。

### 升版流程
`改版本号 → 写 CHANGELOG → 跑测试 → 提交推送 → 生成干净部署源 → 部署 → 线上四项校验`

## 七、核心业务逻辑速览

计价 8 步详见 [`docs/CORE-LOGIC.md` 第二节](../CORE-LOGIC.md)。此处只列**最容易踩坑的规格取档**：

### 规格匹配（v12.9 双模式，`APP_PROFILE.specMatchMode`，默认表格匹配）

| 模式 | 逻辑 |
|---|---|
| **表格匹配**（默认） | ① v7.3 硬编码强制映射（仅出血表）：4000–4999→005、5000–5499→055、5500–6000→006；② 常规：`specs` 中 `maxArea ≥ 面积` 的最小档；③ 超 max → 最大档 × 面积系数（面积/10000，2 位） |
| **规则匹配** | 按「数据管理 → 匹配规则」的规则集（面积上限→代码）选代码；**价格仍取表格中该代码的价格**；未命中（超上限 / 该纸无此代码）自动回退表格匹配 |

- 规则集两套：`global`（除织唛外）+ 织唛专用（`1.3*8=1040 … 5*8=4000`，上限 = 宽(cm)×800）。
- 存 `tagPricing_specMatchRules`，**仅本地，未云同步**。
- 规则模式下 007/008 按面积精确取（6000–6999→007、7000–7999→008），不再合并显示；
  表格模式仍合并显示 `007/008`（两者价格数据完全一致，已核 43/43 张纸）。
- ⚠️ 已知遗留：纸张规格表 maxArea 有 **6 处历史偏差**（003/005/055/006/007/009），
  这正是引入规则匹配的原因；是否修正表格数据**待定**（修了会改变表格匹配的现有报价）。

### 手动代码优先级最高
`manualCode`（▲▼ 切换的代码）先于两种模式（`app.js` `findSpecByDisplayCode`）。

## 十、本机环境坑（都是踩过的，别再踩）

1. **GitHub 推送时通时断**，偶发 schannel 证书吊销失败（`CRYPT_E_NO_REVOCATION_CHECK`）：
   用 `git -c http.sslVerify=false push` + `env -u …` 清代理 + **重试循环 + `ls-remote` 回读校验**（一般 3–5 次内成功）。
2. **禁用 `sed` 改版本号**——多次静默失败，一律用 python 精确替换并断言命中数。
3. **全库 LF**（`core.autocrlf=false`）；`git add` 的 autocrlf 转换不可依赖，批量行尾用 python。
4. 提交用 plumbing（本机 `git merge` 会 SIGTERM 挂起）：`git write-tree` → `git commit-tree` → 写 refs。
5. wrangler 部署需**关闭沙箱**并清代理环境变量。
6. `node --test <目录>` 在本机 Node 22 下误报失败——**必须显式传入测试文件**。
7. jsdom 在 `C:\Users\Mayn\.workbuddy\binaries\node\workspace`（NODE_PATH 引用），不在仓库内。
8. Cloudflare Token **仅会话内使用，不落盘**。
